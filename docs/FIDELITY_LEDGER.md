# Fidelity ledger

Reference: desktop-макет из страницы 2 предоставленного DOCX и исходные assets из Figma. Проверка: Chromium 1280×720 из CI.

| Область     | Reference                                     | Реализация                                 | Итог                                |
| ----------- | --------------------------------------------- | ------------------------------------------ | ----------------------------------- |
| Общая сетка | узкая белая центральная колонка               | `1160px`, поля 60px при 1280               | совпадает по ритму                  |
| Header      | logo, чёрный Каталог, длинный search, account | тот же порядок и пропорции                 | совпадает; logo текстовый           |
| Hero        | чёрный скруглённый баннер, arrows, dots       | 250px, arrows, auto timer, активные dots   | интерактив полнее reference         |
| Сервисы     | 9 цветных иконок + «Ещё»                      | оригинальные Figma assets, 10 равных ячеек | совпадает                           |
| Steam       | одна горизонтальная панель из четырёх зон     | title/login/amount/currency/pay            | совпадает; валюта интерактивна      |
| Товары      | пять плотных PUBG-карточек                    | пять карточек с тем же image и lift hover  | совпадает                           |
| Типографика | нейтральный grotesk, компактные labels        | system Inter/Segoe stack, близкие размеры  | нет layout shift/webfont dependency |
| Узкий экран | отдельный mobile не требуется                 | breakpoints 900/620, grid 2 columns        | overflow проверяет Playwright 390px |

Осознанные отличия: hero содержит полезный русский copy вместо пустого чёрного placeholder; reviews и большой footer не реализованы по прямому исключению ТЗ. Новые изображения не генерировались.
